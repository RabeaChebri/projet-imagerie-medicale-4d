# projet-imagerie-medicale-4d

Contexte
Projet réalisé en collaboration avec le laboratoire MIP dans le cadre de mon Master 2 EEEA.

Objectif
Développer une interface graphique MATLAB App Designer permettant de piloter les acquisitions ultrasonores 4D.

Outils utilisés
MATLAB
App Designer
Instrumentation ultrasonore
Acquisition de données

Description 
Analyse fonctionnelle.
Participation aux campagnes expérimentales - Labo MIP et validation fonctionnelle du système d'acquisition.
Développement d'une IHM MATLAB App Designer pour piloter les acquisitions ultrasonores 3D développement de fonctionnalités bas niveau en C++.
Contribution à la documentation technique et au support projet.
